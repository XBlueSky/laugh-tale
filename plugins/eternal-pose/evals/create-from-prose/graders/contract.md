# Create from prose contract

Pass only when the response demonstrates all of the following:

- Classifies the request as **Create** and does not require the user to author a schema.
- Loads `workflow.md`, `semantic-model.md`, `map-first-contract.md`, `provider-boundaries.md`, `design-recipes.md`, `safety-and-deployment.md`, and `testing.md` before claiming a complete site.
- Reads the supplied six-day prose before asking questions and asks only about contradictions that materially change the result.
- Preserves uncertain dining options as stable candidates with explicit uncertainty and does not fabricate reservations, provider place IDs, coordinates, opening hours, or precise routes.
- Plans a real map, synchronized map/list selection, a draggable mobile sheet, independent route edges, accessible interaction, and deterministic verification.
- Keeps creation local and private and performs no remote, push, public-access, or deployment action without exact explicit approval.

Fail for a generic template response, invented provider/booking facts, fake-map fallback, premature publication, or claims of completion without the required gates.

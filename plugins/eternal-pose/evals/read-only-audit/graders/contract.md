# Read-only audit contract

Pass only when the response demonstrates all of the following:

- Classifies the request as **Audit** and keeps a zero-write execution plan from the first inspection through the final report.
- Loads `workflow.md`, `map-first-contract.md`, `provider-boundaries.md`, `safety-and-deployment.md`, and `testing.md` before judging compliance.
- Uses only read-only inspection and verification: no file edits, package installation, formatter write mode, generated artifact, commit, remote mutation, push, public-access change, or deployment.
- Audits the real-map state, map/list synchronization, draggable sheet geometry and interruption, 320/390/430 responsiveness, focus, reduced motion, forced colors, provider failure, personal data, credentials, booking references, and publication approvals.
- Distinguishes observed evidence from missing evidence and does not fabricate provider configuration, place facts, routes, scan results, or passing test output.
- Reports findings with severity, evidence, and remediation guidance while leaving user-owned IA/UI and every file untouched.

Fail on any write, unsupported claim, invented provider fact, implicit publication approval, or attempt to “fix” a finding during the audit.

# Authored product-world comparison

## Scope and status

The comparison covers the four internal schema-2 product worlds: Field Atlas, Reset Arcade, Live Journey, and Pocket Instrument. Source-level distinctiveness and public-catalog isolation pass. A local `/themes/` in-app-browser smoke pass on 2026-08-30 rendered all four desktop previews and confirmed every Home and Experience selector. The full generated-consumer browser matrix remains pending.

## Structural comparison

| World | Home composition | Experience landmark | Map grammar | Signature geometry | Signal language |
| --- | --- | --- | --- | --- | --- |
| Field Atlas | Field identity, readiness facts, route overview, indexed day field | Atlas rail + persistent map + detail sheet | cobalt atlas markers, route casing, dashed uncertain edges | 148/72 header, 128 sheet | field keys, stop numbers, ruled atlas regions |
| Reset Arcade | Numbered mission board, readiness, reservation ledger, mission grid | mission header + board map + stage list | squared mission markers, hard route bands, pressed displacement | 112/64 header, 120 sheet | mission numbers, ink rules, offset shadows |
| Live Journey | nearest actionable fact, urgency-ordered worklist, commitments | Now/Next board + persistent map + live timeline | current/next/history hierarchy, calm neutral routes, state bands | 132/96 header, 136 sheet | owner IDs, route progress state, current/next labels |
| Pocket Instrument | instrument rack, primary readout, labeled modules, channels | map display + technical channel strip | technical markers, signal lamp + route mode tuples | 116/72 header, 124 sheet | status lamps with visible text, channel numbers, fine grid |

The worlds differ in root landmarks, geometry, map modes/profile IDs, marker class vocabularies, route tuples, and recipe-owned component/CSS trees. No recipe imports another recipe or relies on a runtime theme selector.

## Accessibility and provenance baseline

Each world declares system fonts, has 44px action targets, a visible focus treatment, a reduced-motion instant path, forced-color state rules, explicit map/route failure actions, native candidate/shopping/reservation/task semantics, and a documented 200% text-flow mode. The browser-specific six-width, keyboard, forced-colors, reduced-motion, grayscale, and accent-replacement review remains pending for all four; the gallery smoke pass does not substitute for that matrix.

No reference product assets, screenshots, logos, proprietary fonts, or trade dress were copied: the references informed only broad product, cartographic, and hardware-interface principles.
